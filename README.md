# GBTI 游戏人格测试 🫠

> 一台用于把人类拆解成可被排位系统谴责的电子人格鉴定装置。
> 本产品不保证准确，只保证抽象。

## 产品概述 🧪

GBTI，全称 **Gamer Brain Type Indicator**，是一套完全不需要科学依据的网页人格鉴定系统。它通过 30 道常规题和 2 道隐藏触发题，把受测者从“有温度、有尊严、会呼吸的人类”压缩成 17 种非人物件或游戏机制。

测试结果不用于招聘、相亲、选队友、医院诊断，也不用于任何稍微有意义的用途。

## 核心功能 🎮

- 16 个主型，覆盖 FPS、MOBA、Roguelike/单机、MMO/休闲四类游戏废料。
- 1 个隐藏人格 `ALT-F4`，仅当系统检测到你对烂局产生明确逃离冲动时解锁。
- 四个核心维度：行动风格、沟通状态、胜负心态、团队定位。
- 四个附加方向：资源观、风险偏好、团队意识、逆风反应。

## 如何运行 📟

直接双击 `index.html`。

不需要 `npm install`，不需要后端，不需要服务器，不需要配置环境变量，也不需要理智。


## 计分原理 🧮

核心维度采用“看起来像 MBTI 的多数票制度”：每题给一个极点投票，最后票多者胜。附加方向则把 1 到 3 分归一化成百分比，制造一种“数据很专业”的幻觉。

隐藏人格采用两段触发：第一题负责筛选，第二题负责确认。只有两道题都表现出“这游戏不伺候了”，系统才会把受测者标记为 `ALT-F4`。
